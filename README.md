# HR Workforce Demographics Dashboard

## 📊 Project Overview
This project analyzes the company's workforce composition, salary distribution, and demographics using **Advanced Excel**.

**Key Insights:**
* Analysis of employee headcount by gender and department.
* Salary distribution and averages based on experience.
* Interactive filtering by region and contract type.
